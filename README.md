# Telecom Customer Churn Analysis

## 📌 Overview

An end-to-end customer churn analysis project using SQL, Excel, Power BI, and DAX to identify customer segments associated with high churn and generate actionable business insights.

## 📊 Dataset

* **7,043 customers**
* Telecom customer-level data
* Key dimensions: contract, tenure, payment method, internet service, gender
* Key metrics: monthly charges, total charges, churn status

## 🛠️ Tools & Technologies

* SQL
* Microsoft Excel
* Power BI
* DAX

## 📈 Power BI Dashboard

The interactive dashboard provides:

* Total customers
* Active customers
* Churned customers
* Overall churn rate
* Total revenue
* Average revenue per customer
* Average monthly charges
* High-value customer count
* Churn by contract
* Churn by payment method
* Churn by internet service
* Churn by tenure group
* Contract × tenure churn matrix
* Interactive slicers for customer segmentation

## 🔍 Key Findings

* Overall customer churn rate: **26.54%**
* Month-to-month customers have a **42.7% churn rate**
* Electronic-check customers have a **45% churn rate**
* Fiber-optic customers have a **42% churn rate**
* New customers have a **47% churn rate**
* New month-to-month customers represent the highest-risk segment with a **51% churn rate**

## 💡 Business Insight

The analysis suggests that early-stage customers on flexible month-to-month contracts are particularly vulnerable to churn. Retention strategies focused on new customers, contract conversion, and early engagement could help reduce customer attrition.
